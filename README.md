# Python Automated Inventory & Daily Sales Reporter

An automated Python script designed for retail stock management, daily sales simulation, and dynamic report generation using dictionaries and file I/O operations.

## Key Features
- **File-Based State Management**: Parses and updates persistent inventory levels from formatted text logs.
- **Sales Simulation**: Implements stock boundary validation logic preventing negative inventory counts.
- **Automated Reporting**: Generates formatted daily financial summaries highlighting total revenue and top-performing items.

## How to Run

```bash
python main.py
